# MANDATORY CAM UNIFIED ARCHITECTURE AMENDMENT — NEURAL CAPACITY AND EXPERIENTIAL INTELLIGENCE DOMINANCE

This amendment supersedes the previous model-size specifications and strengthens the requirements concerning the relationship between CAM's continually learning neural intelligence and the pretrained semantic model.

All other requirements from the CAM Unified specification remain mandatory.

Do not restart completed implementation work unnecessarily. Integrate these requirements into the existing architecture, completion manifest, workstream assignments and acceptance tests.

## 1. FUNDAMENTAL DESIGN OBJECTIVE

We are not building a powerful pretrained language model with a relatively small reinforcement learning controller attached.

We are building a powerful, continually learning neural intelligence that possesses language, programming and semantic understanding as capabilities.

The vast majority of CAM's newly acquired strategic intelligence should emerge through its own experiences, neural learning, experimentation, predictive understanding and adaptation.

The pretrained semantic model exists primarily to provide an initial understanding of human language, code, documents, websites and existing knowledge.

CAM's continually trained neural core must have primary authority over:

- Strategic reasoning.
- Causal understanding.
- Hypothesis generation.
- Experiment selection.
- Numerical latent reasoning.
- Multistep imagination.
- Goal-directed planning.
- Strategy invention.
- Action selection.
- Learning from consequences.
- Long-term capability acquisition.

Do not allow the pretrained language model to independently perform these functions while CAM merely selects among its outputs.

## 3. MAKE CAM THE PRIMARY INTELLIGENCE ARCHITECTURALLY

Implement the following five mechanisms as mandatory components of the architecture.

### Mechanism A: Multilayer latent conditioning

The pretrained semantic decoder must be conditioned directly on CAM's high-dimensional numerical reasoning state.

Define:

Z_t = CAM_θ(observations, previous state, beliefs, memory, goals)

Where, for the main configuration:

Z_t ∈ R^(B × 128 × 1536)

The semantic decoder must receive trainable projections of Z_t through multiple internal layers.

Do not rely exclusively on:

- Written instructions generated by CAM.
- A natural-language system prompt.
- A single conditioning vector.
- A small prefix that the decoder can ignore.
- Independently generated LLM strategies.

Implement latent cross-attention at multiple depths of the semantic decoder.

For example:

H'_l = H_l + α_l · CrossAttention_l(H_l, P_l(Z_t), P_l(Z_t))

Where:

- H_l is the pretrained decoder's hidden state.
- P_l is a trainable projection from CAM's latent representation.
- α_l is a bounded, trainable conditioning gate.

Initialize the conditioning pathway so that it preserves useful pretrained semantic competence while allowing CAM's influence to grow through training.

The semantic decoder's output must measurably depend on CAM's internal numerical state.

Train this dependency through actual action outcomes, action reconstruction, semantic grounding and policy learning.

### Mechanism B: Mandatory consequential decision bottleneck

CAM must control the actions that actually affect its environment.

The pretrained semantic model must not have independent access to execute tools, operate the environment, deploy software or choose final consequential actions.

Use a computational pathway of:

Observation → CAM latent reasoning → CAM action intent → CAM-conditioned executable action generation → CAM evaluation and selection → Environment execution.

Represent action intent numerically:

I_t = Intent_θ(Z_t, B_t, G_t, M_t)

The intent representation should contain sufficient learned information to condition the generation of a specific executable action or strategy.

The semantic decoder translates this latent intent into valid language, source code, tool arguments or other executable representations.

CAM must evaluate the resulting executable action before execution, including the actual code or arguments, not merely the original abstract intent.

The execution layer must reject actions that lack the required CAM authorization and environment permissions.

This must not devolve into a weak controller choosing between a handful of independently generated LLM strategies.

CAM must learn to originate increasingly effective action intents, candidate actions and longer strategies itself.

### Mechanism C: CAM-controlled gated semantic cross-attention

Pretrained semantic representations should inform CAM's thinking without dominating it.

Let:

S_t = SemanticEncoder_ψ(O_t)

Where S_t contains pretrained semantic representations.

At CAM layer l:

R_l = F_θ,l(Z_l)

C_l = CrossAttention_θ,l(Z_l, S_t, S_t)

g_l = sigmoid(Gate_θ,l(Z_l, C_l, B_t, G_t))

Z_(l+1) = Z_l + R_l + g_l ⊙ C_l

CAM must learn how much semantic information it needs and which information is relevant to its current reasoning.

Use appropriate normalization and bounded gates to prevent the pretrained semantic pathway from overwhelming CAM's internally generated representations.

Support gating at the token, attention-head or feature level where computationally appropriate.

Semantic information should remain available throughout reasoning, but the central computational transformations must occur within CAM's own trainable neural backbone.

Do not impose an arbitrary permanent 90/10 activation ratio.

Instead, establish CAM's functional dominance through architectural control and experimental evidence.

### Mechanism D: Independent learned world model, value functions and planning

CAM must possess its own learned understanding of consequences.

Do not ask the pretrained language model whether an action is strategically good and use that answer as CAM's value function.

CAM must learn:

p_θ(Z_(t+1), O_(t+1), Y_(t+1) | Z_t, A_t, B_t)

Its own goal-conditioned value:

V_θ(Z_t, B_t, G_t)

Its own action policy:

π_θ(A_t | Z_t, B_t, G_t, M_t)

Its own exploration policy.

Its own uncertainty estimates.

Its own multistep belief-aware imagination.

These functions must be trained from observed environmental experiences and independently verified outcomes.

The pretrained semantic model may help represent a potential action, but CAM determines whether the action is promising, informative, costly or likely to produce the desired consequences.

When imagining alternative future strategies, perform the central reasoning within CAM's high-dimensional numerical representations.

Do not substitute repeated natural-language conversations with the pretrained LLM for actual latent world-model reasoning.

### Mechanism E: End-to-end experiential neural training

Environmental experiences must continually update CAM's actual core neural weights.

The integrated objectives must include:

- Action-conditioned predictive learning.
- Semantic grounding.
- Fast adaptation learning.
- Goal-conditioned reinforcement learning.
- Learned exploration.
- Multistep imagination learning.
- Memory retrieval learning.
- Long-horizon credit assignment.
- Meta-learning for rapid acquisition of unfamiliar capabilities.
- Continual retention and plasticity.

The gradients must reach the shared strategic intelligence.

Instrument and verify gradients through:

- Early, middle and late CAM transformer layers.
- Semantic input projections.
- Latent reasoning computations.
- Adaptive belief representations.
- World-model computations.
- Action-intent generation.
- Semantic decoder conditioning.
- Learned exploration.
- Policy and value functions.

Do not claim end-to-end learning when only the final action-selection head receives reinforcement learning gradients.

The semantic model may initially remain mostly frozen, but gradients must still propagate through its differentiable computations into the trainable CAM conditioning pathways.

Freezing semantic-model parameters must not accidentally detach CAM's latent inputs.

For non-differentiable executable actions, use correctly implemented policy-gradient credit assignment rather than pretending gradients flow through the environment.

When actions contain generated tokens or arguments, record the relevant generation and selection probabilities. Correctly distinguish learning the action generator from learning only a candidate selector.

## 4. INITIAL SEMANTIC MODEL AND PROGRESSIVE PLASTICITY

Use an approximately 4B-parameter pretrained language/code model as the initial semantic foundation.

Initially:

- Approximately 1B fully trainable CAM core parameters.
- Approximately 4B mostly frozen pretrained semantic parameters.
- Trainable semantic projections and multilayer conditioning mechanisms.
- Trainable semantic adapters where necessary.

Progressively support:

1. Trainable semantic input and output projections.
2. Trainable low-rank adapters throughout selected semantic layers.
3. Selective unfreezing of semantic-model blocks.
4. Joint continual training of the strategic core and semantic backbone.
5. Full joint training when sufficient compute and retention mechanisms are available.

The architecture should eventually support 5–10B or more continually trainable parameters.

Do not permanently assume that the pretrained semantic representation is optimal for experiential intelligence.

Environmental experience should eventually be able to reshape semantic representations themselves.

However, protect useful pretrained language and programming capabilities through retention evaluation, replay and appropriate training schedules.

## 5. TRAIN CAM TO DEVELOP ITS OWN STRATEGIES

The model must not become dependent on pretrained strategic suggestions.

During training, compare:

- Full semantic grounding with CAM-controlled reasoning.
- Semantic grounding with reduced LLM strategic assistance.
- CAM-generated latent action intents.
- CAM-conditioned executable action generation.
- Frozen LLM-generated candidate strategies.
- Direct pretrained LLM control as an explicit baseline.

Gradually reduce dependence on independent LLM strategic proposals as CAM becomes competent.

Where useful, apply distillation from successful experience into CAM's action generation and latent reasoning.

Distill actual useful behavioral patterns, verified outcomes and learned representations.

Do not simply imitate lengthy written reasoning traces and claim this constitutes experiential intelligence.

The objective is for CAM to acquire reusable strategic and causal knowledge through experience that can surpass the original pretrained model's competence.

## 6. EXPERIMENTALLY VERIFY CAM'S STRATEGIC DOMINANCE

A claim that CAM supplies 90% of the intelligence cannot be established through parameter counts or activation magnitudes.

We need causal behavioral evidence.

Implement the following mandatory evaluation conditions:

### Condition A — Original pretrained semantic model

The pretrained model operates with identical environment tools and comparable budgets but without the CAM learning architecture.

### Condition B — Untrained CAM

The complete architecture before experiential training.

### Condition C — Continually trained CAM

The complete architecture after accumulated environmental experience.

### Condition D — Reset CAM strategic weights

Preserve the trained semantic infrastructure while resetting CAM's strategic core to its initial checkpoint.

Measure how much acquired competence disappears.

### Condition E — Remove historical memory

Preserve trained neural weights while removing access to historical task-specific memory and replay.

Measure persistent parametric competence.

### Condition F — Disable CAM's semantic decoder conditioning

Measure whether removing CAM's latent influence causes the action decoder to revert toward pretrained strategies.

### Condition G — Latent-state intervention

Hold semantic observations constant while replacing CAM's latent reasoning state with states representing different goals, beliefs or intended actions.

Verify that executable actions change appropriately.

### Condition H — Frozen CAM core

Allow memory and fast adaptation but prevent permanent core-weight updates.

Compare lifetime learning with the continually trained version.

### Condition I — Semantic-only continual learning

Train semantic adapters without allowing CAM's strategic core to learn.

Determine whether observed improvements originate primarily from the strategic intelligence or the pretrained semantic pathway.

Evaluate these conditions across:

- Unfamiliar OpenWorld objectives.
- Business creation.
- Software invention.
- Causal discovery.
- Long-horizon adaptation.
- Cross-domain transfer.
- Learned experimentation.

Match experience and compute budgets where possible.

Report the absolute performance of every condition.

Estimate how much acquired competence depends on CAM's learned parameters.

Do not interpret this as an exact decomposition of intelligence, because the components can interact and contribute jointly.

Nevertheless, the desired result is that removing CAM's experiential learning eliminates most of the newly acquired strategic competence while preserving much of the underlying language and coding ability.

## 7. SCALE INTELLIGENCE WITHOUT SACRIFICING LEARNING EFFICIENCY

The 1B model is the main architectural target, not proof that larger models learn more efficiently.

Run scaling comparisons across approximately:

- 20M.
- 150M.
- 500M, if practical.
- 1B.
- Larger configurations when authorized resources permit.

Measure:

- Experiences required to acquire a capability.
- Performance after equal environment interactions.
- Performance after equal training compute.
- Unfamiliar-task adaptation speed.
- Long-term retention.
- Cross-domain transfer.
- Actual OpenWorld goal achievement.

Investigate whether smaller learners can accelerate the training of larger learners through experience distillation, representation transfer or progressive scaling.

Use mixed precision, activation checkpointing, efficient attention, microbatching, gradient accumulation and shared semantic-model inference.

Benchmark the main configuration on the actual available hardware.

Do not silently reduce model capacity to 500K or a few million parameters to obtain faster experimental results.

If available hardware cannot support meaningful full-scale training, still implement and exercise the complete main architecture where feasible, document the measured blocker and preserve a reproducible training configuration.

Do not acquire additional paid compute without authorization.
