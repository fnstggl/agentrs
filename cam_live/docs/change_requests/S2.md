# Change requests of S2 (substantive evaluation on 257267c)

## S2-1 (config, master-owned): a code snapshot silently takes a private GPU lock

**What.** `cam_live.config.GPU_LOCK_PATH` defaults to `<REPO_ROOT>/runs/gpu_heavy.lock` where `REPO_ROOT` is two
levels above the imported package (G2I-10). The evaluation runs a `git archive` snapshot of `cam_live/`
(`runs/cam_live/eval/snapshots/<sha>/cam_live/src`), so there `REPO_ROOT` is the snapshot directory, which has no
`runs/`: `gpu_lock()` / `GpuLease` create `<snapshot>/runs/gpu_heavy.lock` and flock a file nobody else takes. The
shared lock of this machine (`/workspace/agentrs/runs/cam_unified/gpu_heavy.lock`, reached through the worktree's
`runs/gpu_heavy.lock` symbolic link) would not be respected.

**Workaround in use (S2).** `CAM_LIVE_GPU_LOCK=/workspace/agentrs/runs/cam_unified/gpu_heavy.lock` in
`scratchpad/S2/env5.sh`; the batch started at 05:52:44 UTC used the worktree's symbolic link to it (same inode
2227280760; `fuser` and `/proc/locks` checked during the first lease, `scratchpad/S2/oe_batch.log`).

**Proposed change.** Fail closed instead of creating a new lock file in a directory that did not exist:

```diff
-GPU_LOCK_PATH = os.environ.get("CAM_LIVE_GPU_LOCK", os.path.join(REPO_ROOT, "runs", "gpu_heavy.lock"))
+GPU_LOCK_PATH = os.environ.get("CAM_LIVE_GPU_LOCK", os.path.join(REPO_ROOT, "runs", "gpu_heavy.lock"))
+#: a copy of the code outside a checkout (e.g. an evaluation snapshot) must name the shared lock explicitly
+GPU_LOCK_EXPLICIT = "CAM_LIVE_GPU_LOCK" in os.environ or os.path.exists(GPU_LOCK_PATH)
```
and in `nn.gpu.gpu_lock` / `runtime.gpu_cycle.GpuLease.acquire` / `harness.visual` / `grounding.bench`:
`if not GPU_LOCK_EXPLICIT: raise GpuUnavailable("no shared GPU lock file at ... and CAM_LIVE_GPU_LOCK unset")`
instead of `os.makedirs(os.path.dirname(GPU_LOCK_PATH)); open(GPU_LOCK_PATH, "a+")`.
