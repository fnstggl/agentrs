  device auto (cuda) WITHOUT the shared GPU lock (only real_model=True takes it). Measured: staging_config(_cfg(''), False, 0) ->

  '1459 tests collected, 1 error' (exit 2). cam-live test without --suite runs exactly that and fails the same way.

  so a bare 'cam-live run --authorization F' fails in the supervisor (register_live_authorization: 'operator public key not
  installed'); tools/launch_live.sh (d086a55) installs it before cam-live run.

  backbone on the shared GPU for the whole run (by design for a persistent run; on this shared machine it must be coordinated).
