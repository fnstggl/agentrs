# Component C2: recommendation, consumption and audience (`crucible.social`)

Workstream C2, Crucible 5.0. Contracts: [INTERFACE_CONTRACTS.md](../INTERFACE_CONTRACTS.md) section 3
(`consumption()`, `impressions()`, `audience()`, the `Recommender` protocol). Requirements: D.1-D.5, I.1-I.7, I.n1,
I.n2, SP-4.5, SP-4.6.

## The view threshold

a view requires watch_s >= min(30 s, 0.5 x duration_s)

A consumption row (one viewing by one individual) is a view exactly when `watch_s >= min(30, 0.5 * duration_s)`
and the viewer is not the item's creator. `crucible.social.audience.VIEW_RULE`, `VIEW_MIN_S = 30`,
`VIEW_MIN_FRAC = 0.5`, `view_threshold(duration_s)`. An exposure (impression) is never a view; a consumption row
needs an earlier exposure of the same individual to the same item.
